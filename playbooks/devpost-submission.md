# Devpost submission

Use the event's actual form; Devpost fields vary. Create a draft soon after choosing the idea and maintain it as the project evolves. For a short event, target a complete entry before final freeze; for a multiweek challenge, Devpost suggests submitting well ahead of the deadline. Edits to the submission stop at its deadline even if a portfolio project remains editable.

## Project story

Lead with a one-line value proposition and a working visual. Then describe the user problem, what the project does, the demo route, how it was built, technical challenge and resolution, outcome/evidence, limitations, and next steps. Separate shipped features from plans. Use screenshots with captions and a simple architecture diagram when it clarifies implementation.

Order the media to follow the actual product journey: result or hero image, starting input, in-progress state, final output, and technical proof. For each screenshot, write a caption that tells a judge what happened. Include a real obstacle and the resulting design choice or pivot. If a subsystem was unreliable during judging, say so explicitly and show the working portion.

## Final checklist

- [ ] Eligibility, build window, prior-work/AI policy, team roster, track limit, and category confirmed against current rules.
- [ ] Project name, tagline, problem, solution, and build story accurately match the demo.
- [ ] Required sponsor tools are tagged and their use explained with proof.
- [ ] Repository and live demo links open without special access; README starts the app; license matches event rules.
- [ ] Video length, content, hosting, public visibility, and event-specific intro comply with rules. Check the **submission's** video, not just the portfolio page.
- [ ] Screenshots show real current functionality; mock or sample data is labeled.
- [ ] All required fields, attachments, team members, challenge selections, and terms are complete.
- [ ] Submission is sent before the deadline in its published timezone; confirmation and final preview are checked.

Devpost's help center describes the submission steps, video hosting, and edit cutoff; see [sources](../references/sources.md). Do not assume YouTube privacy modes or external links satisfy a particular contest without checking its rules.
