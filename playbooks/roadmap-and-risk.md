# Roadmap, timeboxing, and risk

## Before the event

Read eligibility, prior-work, team, venue, and submission rules. Ideate, learn tools, arrange accounts/hardware, and prepare a legal starter only if allowed. Check network, demo device, capture software, and media hosting. Reserve roles: product/demo owner, integration owner, UI owner, and submission owner; one person may hold multiple roles.

## During the event

Use event-relative percentages, then adapt to actual judging and sleep needs:

| Point | Required state |
| --- | --- |
| 0–10% | Rules matrix, idea decision, one-page contract, draft Devpost entry |
| 10–35% | Real vertical slice with one input and result |
| 35–65% | Core feature complete, integration checks, first mock demo |
| 65–80% | Fix top rubric gaps, polish key UI, capture screenshots |
| 80–90% | Feature freeze, rehearse, record and upload demo |
| 90–100% | Verify final links, team members, track fields, submit, confirm receipt |

These are heuristics, not a substitute for actual event deadlines. For a 24-hour event, plan a real sleep/meal break and move submission earlier if video upload or venue connectivity is uncertain. For longer online events, use weekly milestones and submit a complete draft well before the deadline; Devpost recommends early submission and permits edits before cutoff.

## Risk register

Track each risk as **probability × impact**, owner, trigger, mitigation, fallback. Include API access/quota, data availability, deployment, device/network, merge conflicts, permissions, video processing, and deadline/timezone. Revisit at each checkpoint. A provider outage should lead to a transparent sample or local fallback, never a fake live claim.

## Cut rule

When behind, cut in this order: extra tracks, extra platforms, optional integrations, visual effects, secondary features. Preserve the core user path, required sponsor proof, demo capture, and valid submission. Freeze new dependencies before recording. Submit a complete version early, then improve it only while the event permits editing.
